# 📘 Skill: selector-extraction-manager

## Skill ID

selector-extraction-manager

## Purpose

Extract and centralize `data-testid` selectors from frontend
repositories into structured JSON for maintainable Playwright
automation.

## Capabilities

-   Scan Vue/Nuxt components
-   Detect data-testid attributes
-   Generate selectors.json
-   Replace hardcoded selectors
-   Enforce meaningful naming

## Constraints

-   Do not modify business logic
-   Do not inject selectors automatically without confirmation

## Success Criteria

-   Centralized selector repository created
-   No hardcoded selectors in test files
