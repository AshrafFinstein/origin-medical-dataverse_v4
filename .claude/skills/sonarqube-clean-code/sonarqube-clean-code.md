# 📘 Skill: sonarqube-clean-code

## Skill ID

sonarqube-clean-code

## Purpose

Ensure Playwright automation adheres to SonarQube clean coding
standards.

## Capabilities

-   Remove magic strings
-   Enforce explicit TypeScript types
-   Reduce cyclomatic complexity
-   Suggest modularization
-   Detect duplicate logic

## Constraints

-   Do not introduce unnecessary abstraction
-   Maintain readability

## Success Criteria

-   Low code smell index
-   Maintainable automation suite
